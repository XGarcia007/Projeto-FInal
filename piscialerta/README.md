# PisciAlerta

Sistema IoT off-grid para monitoramento de oxigênio dissolvido, pH, amônia tóxica e bateria solar em piscicultura.

## Módulos

- `firmware/`: aplicação C++ para ESP32 e decisões locais de segurança.
- `backend/`: API Node.js para telemetria e integração de alertas.
- `frontend/`: dashboard web responsivo para operação em campo.
